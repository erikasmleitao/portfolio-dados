
# 📊 Mini-Projeto: Análise de Dados de RH com Power BI

Este projeto tem como objetivo apresentar uma introdução prática à análise de dados de **Recursos Humanos (RH)** utilizando o **Power BI**.  
Através da construção de um dashboard interativo, exploramos diversas funcionalidades da ferramenta, como:

- Criação de tabelas de medidas  
- Uso de colunas condicionais  
- Visualizações dinâmicas e filtros interativos  

---

## 🧠 Perguntas de Negócio Respondidas

O dashboard foi desenvolvido para responder às seguintes questões estratégicas:

1. Total de funcionários atualmente na empresa  
2. Tempo médio de experiência dos colaboradores (em anos)  
3. Distribuição de gênero: total e percentual de funcionários masculinos e femininos  
4. Média salarial mensal dos funcionários  
5. Total de funcionários por função (ex.: Cientista de Dados, Engenheiro de IA, etc.)  
6. Percentual de disponibilidade para hora extra  
7. Nível de envolvimento no trabalho, categorizado em: Ruim, Baixo, Médio e Alto  
8. **Cálculo adicional (fora do dashboard):** Total e percentual de funcionários elegíveis para promoção, com base na coluna *Anos de Experiência*  

---

## 📌 Observações

- Os dados utilizados são **fictícios** e servem apenas para fins educacionais.  
- O item 8 foi calculado separadamente e não está representado visualmente no dashboard.  
- O projeto pode ser expandido com análises preditivas, segmentações por departamento e indicadores de desempenho.
